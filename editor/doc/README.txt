Dagon Editor documentation theme

Files:
- index.md / index.html: documentation overview (landing page)
- viewport.md / viewport.html: Viewport guide
- template.html5: shared Pandoc HTML5 template
- style.css: shared offline stylesheet
- convert.bat: rebuilds both HTML pages with Pandoc

Build:
1. Put Pandoc in PATH.
2. Run convert.bat from this directory.
3. Open index.html directly in a browser.

The theme has no external fonts, scripts, stylesheets, or runtime dependencies.
The sidebar links and breadcrumbs are ordinary relative links and work with file://.
