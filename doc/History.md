# Dagon History

Dagon was started in late 2016 as an overhaul of [DGL](https://github.com/gecko0307/mathom/tree/master/dgl), a minimalistic 3D and 2D real-time graphics engine written in D language using OpenGL and SDL 1.x. DGL was an engine backing [Electronvolt](https://github.com/gecko0307/electronvolt) (formerly known as Project Atrium), a discontinued first-person puzzle game. Work on Atrium showed that the engine lacked necessary tools for certain tasks, and was in many ways not efficient enough. Furthermore, a discussion on Reddit raised the question of why DGL does not use SDL2. This led to the creation of a new branch of the engine, which ultimately became a separate project.

Creator and key maintainer of Dagon is [Timur Gafarov](https://github.com/gecko0307) aka gecko0307, a professional game developer from Kazan, Russia. Timur started his career as a web designer and worked in online advertising, creating HTML5 games and interactive ads. He is also creator of [dlib](https://github.com/gecko0307/dlib) and numerous other Open Source projects in D.

In 2017, Dagon was rewritten using OpenGL 3.3, shedding the legacy of the fixed-function pipeline. For a time, the engine utilized a clustered forward renderer before transitioning to a deferred rendering architecture. At its core, the engine's renderer is based on PBR, which has undergone significant evolution over the years, incorporating a wide array of features such as HDR, subsurface scattering, volumetric lighting, area lights, decals, light probes, and more.

In 2018, [sacengine](https://github.com/tg-2/sacengine/), an open implementation of the game *Sacrifice*, was developed using Dagon as its foundation. That same year, Dagon also switched to using BindBC for the dynamic linking of C libraries.

In 2019, new contributors joined the project. [Mateusz Muszyński aka Timu5](https://github.com/Timu5) added support for the Nuklear GUI toolkit. Thanks to the efforts of Rafał Ziemniewski, support was implemented for landscapes—either loaded from heightmaps or generated using OpenSimplex noise. During this period, Timur began work on integrating the Newton physics engine. Also that year, a game was released to showcase the capabilities of Nuklear within Dagon: [DagoBan](https://github.com/Timu5/dagoban), a mini-clone of Sokoban featuring a built-in level editor.

In 2020, the renderer was significantly rewritten, taking on the form in which it exists today. It became possible to write a custom render pipeline and integrate it into the application. Support for DDS textures was also added.

The year 2021 saw the introduction of support for glTF 2.0, which gradually replaced the engine's legacy custom scene format. Dagon now offers strong compatibility with glTF files exported from Blender. Additionally, support for DDS cubemaps was added, along with new post-processing effects.

In 2022, the engine's texture-loading system was completely rewritten; it now allows for the creation of textures directly from memory buffers, eliminating the need for intermediate `SuperImage` objects. Support for the ImGui toolkit was integrated, and a new landscape texturing system was introduced.

In 2023, the engine got support for 1D and 3D textures, Hald CLUTs, subsurface scattering, and light probes.

2024 saw the introduction of the new AgX tonemapper, Wayland support on Linux, and an improved OBJ loader. Dagon was featured at the FOSDEM '24 conference in Brussels during a presentation on the D programming language.

2025 brought a vast number of improvements to the engine. Here are some of the most significant ones: a transition to OpenGL 4.3; multithreading and asynchronous messaging; compute shaders; support for GPU skinning and animated glTF models (thanks to [Denis Feklushkin aka denizzzka](https://github.com/denizzzka) for implementing the base classes required for animation); HiDPI support; integration with virtual reality devices via the OpenVR API; a switch to SDL2_Image for texture loading, enabling support for new formats such as WebP, AVIF, SVG, and many others; support for KTX/KTX2 textures with Basis Universal transcoding into various compression profiles, as well as saving to the KTX2 format; video textures decoded via the libVLC library; an audio engine; support for anisotropic texture filtering; shadows for positional light sources; cubemap pre-filtering; volumetric scattering for positional lights; box projection for environment probes; a simplified renderer (`SimpleRenderer`) for casual games and retro-style graphics; an ocean shader; a built-in collision detection engine; a custom logger; a basic native GUI toolkit; and support for application localization.

2026 — In April of this year, Dagon 1.0.0 was released. The engine gained integration with the Jolt Physics engine, support for volumetric cone light sources, built-in BC1, BC3, BC4, BC5 and BC7 compressors, the ability to save textures in the DDS format, new Uchimura and Lottes tonemappers, a Contrast Adaptive Sharpening (CAS) filter, auto-exposure, vignette and film grain effects, FXAA 3.11, and a networking extension. Work also began on a scene editor. Furthermore, development of Dagon 2.0 began that same year.
