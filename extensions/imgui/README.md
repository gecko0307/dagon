# dagon:imgui

Immediate mode GUI extension that uses [Dear ImGui](https://github.com/ocornut/imgui) via a fork of [i2d-imgui](https://github.com/Inochi2D/i2d-imgui) dynamic binding. It allows to implement sophisticated user interfaces, turning Dagon into a generic application framework. ImGui supports windows, tab-based window docking, all kinds of widgets, menus, tables, grid view, image display, drag and drop mechanics, color pickers, and much more. While you can use ImGui as a main UI toolkit for your game, it is best suited for development tools, such as in-game editors, configurators and debug overlays.
